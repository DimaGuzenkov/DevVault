# DevVault

Android-приложение: личная офлайн-база знаний программиста. Ссылки,
заметки и файлы с поиском. Назначение описано в [VISION.md](./VISION.md).

## Возможности

- Сохранение ссылок из браузера через «Поделиться».
- Создание заметок.
- Прикрепление файлов (PDF, EPUB, изображения, текст).
- Управление тегами: создание, переименование, удаление.
- Поиск по заголовку и содержимому, фильтры по типу, тегу и избранному.
- Редактирование, удаление, избранное.
- Хранение данных между запусками приложения.

## Сценарии

**Сохранение ссылки из браузера.** Пользователь делает долгое нажатие
по ссылке → «Поделиться» → DevVault. Открывается редактор
с заполненным URL. Пользователь добавляет теги и сохраняет.

**Создание заметки.** Пользователь открывает приложение → «Добавить» →
«Заметка», вводит заголовок и текст. Добавляет теги и сохраняет.

**Прикрепление файла.** Пользователь открывает приложение → «Добавить» →
«Файл», вводит заголовок, нажимает «Прикрепить» и выбирает файл
в системном диалоге. Файл копируется внутрь приложения. Пользователь
добавляет теги и сохраняет.

**Работа с тегами.** В редакторе записи пользователь вводит название
тега. Приложение показывает подходящие существующие теги; можно выбрать
один из них или подтвердить ввод нового — тег создаётся и сразу
привязывается к записи. На отдельном экране тегов пользователь видит
список всех тегов со счётчиком записей, может переименовать тег
или удалить его. При удалении тег снимается со всех записей,
сами записи сохраняются.

**Поиск.** Пользователь открывает список записей, вводит запрос.
Результаты фильтруются по заголовку и содержимому. При необходимости
применяет фильтр по типу, тегу или избранному и открывает запись.

**Редактирование и удаление.** Пользователь открывает запись, меняет
заголовок, содержимое, теги или вложения. При удалении записи
удаляются её вложения и файлы на диске.

## Критерии готовности

- Приложение запускается на устройстве или эмуляторе и работает
  без интернета.
- Ссылка из браузера открывается в редакторе с подставленным URL.
  Повторный шаринг не создаёт второй экземпляр экрана.
- Создаются заметки, ссылки и записи с файлами.
- Файл прикрепляется через системный диалог без разрешений
  на хранилище.
- Удаление записи удаляет её вложения и файлы; удаление вложения
  удаляет файл.
- В редакторе записи можно добавить тег: при вводе показываются
  подходящие существующие теги, новый тег создаётся из введённого
  названия.
- Названия тегов нормализуются: обрезаются пробелы по краям,
  регистр приводится к нижнему, дубликаты не создаются.
- Есть экран со списком всех тегов и количеством записей в каждом.
- Тег можно переименовать; новое название отражается во всех записях.
- Тег можно удалить; он снимается со всех записей, записи сохраняются.
- Поиск идёт по заголовку и содержимому; фильтры комбинируются.
- Сортировка (по обновлению, созданию, алфавиту) сохраняется
  между запусками.
- После перезапуска данные сохраняются.
- Поворот экрана и смена темы не сбрасывают ввод и фильтры.

## Технологии

Kotlin, Jetpack Compose, Material 3. Состояние — ViewModel и StateFlow,
асинхронность — Coroutines и Flow. Хранение — Room для метаданных,
внутреннее хранилище приложения для файлов, DataStore для настроек.
Навигация — Navigation Compose. Файлы — SAF для выбора и FileProvider
для открытия.
