# DevVault

## Что это

Android-приложение для личной офлайн-базы знаний программиста.
Пользователь сохраняет ссылки, заметки и файлы, а позже находит
их поиском.

## Для кого

Для разработчика, который учится или работает и регулярно
возвращается к темам, с которыми уже разбирался. Приложение личное:
один пользователь, без аккаунтов и синхронизации.

## Проблема

Материалы, которые нужны в работе, хранятся в разных местах: вкладки
браузера, закладки, чаты, папка «Загрузки». Когда материал нужен снова,
найти его сложно, и часто проще загуглить заново. Время теряется,
накопленный опыт не используется.

Отдельная сложность — сохранение. Если на сохранение уходит много
действий, пользователь этого не делает, и база остаётся пустой.

## Решение

1. **Быстрое сохранение.** Ссылку из браузера можно отправить
   в приложение через «Поделиться»: URL уже подставлен, остаётся
   добавить теги и сохранить. Заметки и файлы создаются за несколько
   действий.
2. **Надёжный поиск.** Поиск по заголовку и содержимому, фильтры
   по типу, тегу и избранному. Записи организуются тегами: одна
   запись может относиться к нескольким темам одновременно.

Приложение работает без интернета. Все данные хранятся на устройстве.
